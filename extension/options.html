译流 · YiLiu

一个把大模型带进 Safari 的整页与划词翻译扩展。

版本1.0.0
快捷键⌥ A
翻译方式整页 · 划词
数据去向仅你的 API

译流不会收集、上传或分析你的浏览内容。整页翻译会把页面中的文字发送到你在 「翻译服务」中配置的 API 地址；划词翻译只发送选中的文字及少量上下文。缓存保存在本机， 可随时清除。
