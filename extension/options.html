推荐 API

大模型 API 是飞译向模型发送文字、取回译文的接口。API Key 是服务商发给你的访问密钥。

  1. 在服务商后台开通 API，按需设置计费或充值，再创建 API Key。
  2. 在飞译选择服务商，粘贴 API Key。
  3. 点击「连接服务」并开始翻译。

数据如何处理

网页文字
整页翻译按当前可见内容逐步处理，会跳过密码框和其他表单输入。划词翻译处理你选中的文字。网页正文可能包含姓名、邮件或私密消息，这些文字一旦参与在线翻译，也会发给服务商。
页面上下文
开启「发送页面标题及必要上下文」后，整页翻译可能附带页面标题和站点域名，划词翻译可能附带标题和选区前后的文字。
API Key 与设置
密钥随请求发给你配置的服务商，用于认证。飞译不会将密钥上传到自己的服务器。导出的设置文件会省略 API Key 和自定义请求头。
本地翻译缓存
启用缓存时，译文保存在本机，以便下次复用。你可以在「更多阅读设置」中关闭缓存或清除已有缓存。

你可以管理的设置

网站访问权限
Safari 的网站访问权限让飞译能在获准的网站上读取待译文字并显示译文。你可以在 Safari 的「设置 → 扩展」中管理网站访问。
站点自动翻译
可在工具栏弹窗关闭当前网站的自动翻译，也可在「更多阅读设置」中管理自动翻译和排除的域名。
发送上下文
关闭「发送页面标题及必要上下文」后，翻译请求会省略上述页面上下文。

常见问题

翻译服务商会保留文字吗？

服务商对请求内容的保存、使用和删除规则，以该服务商的条款和隐私政策为准。你可以在开通 API 前查看相应说明。

翻译请求怎样传输？

内置的在线服务使用 HTTPS。自行接入服务时，传输方式取决于填写的 API 地址。连接远程服务时请使用 HTTPS。

哪些操作可以在本机完成？

简体转繁体可以在本机完成。你也可以配置 Ollama 或 LM Studio 等本机模型服务，让翻译请求发往本机地址。

如何反馈隐私或安全问题？

可通过联系作者反馈。描述问题时请隐去密钥及私密原文。
